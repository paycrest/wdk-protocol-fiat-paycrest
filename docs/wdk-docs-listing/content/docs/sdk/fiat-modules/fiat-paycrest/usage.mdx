# Usage

The [@paycrest/wdk-protocol-fiat-paycrest](https://www.npmjs.com/package/@paycrest/wdk-protocol-fiat-paycrest) module quotes, creates, and tracks Paycrest on-ramp and off-ramp orders. Run the module in your app and its order callbacks against your backend, then use the guides below for setup, buy and sell flows, and transaction follow-up.
